## 📌 Overview

ICU AI Assistant is an explainable AI-assisted clinical decision support platform designed to support:

- Arterial Blood Gas (ABG) interpretation
- Acid-base disorder analysis
- Oxygenation assessment
- Ventilator consideration prompts
- Longitudinal ICU trend analysis
- Explainability-driven clinical reasoning

The platform combines:
- rule-based physiological interpretation,
- machine learning-assisted classification,
- oxygenation analytics,
- and trajectory monitoring

within a modern ICU-style dashboard environment.

## 🧠 Clinical Workflow Philosophy

The platform is designed around real ICU cognitive flow:

1. Detect instability
2. Prioritize life-threatening abnormalities
3. Interpret primary acid-base disorder
4. Assess compensation
5. Evaluate oxygenation
6. Review ventilator considerations
7. Analyze longitudinal trends
8. Support explainable clinical reasoning
